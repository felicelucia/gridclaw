The generalist loop

One engine. Three capabilities. Every country.

GridClaw is a generalist engine that, in every country, understands where to get the information, learns it, and then acts on it.

01 · UNDERSTAND

Find the right sources

Locate the regulator, the grid operator, the tender platforms and the laws that govern a project — without a human telling it where to look.

02 · LEARN

Read & structure

Parse heterogeneous rulebooks into one common Format, kept alive via RAG so norms and rulings never go stale.

03 · ACT

Compute, simulate, contact

Run the real IRR, simulate scenarios, compare schemes, and route the dossier to the right counterparty.

Compounding moat

The engine remembers.

Every analysis is stored in a structured memory. Past projects inform new ones — comparables, counterparties, connection corridors. The dataset is the moat.

Every analysis makes GridClaw smarter. +1 memory written each time the engine runs.

Built to be forked

A generalist kernel.
One module per country.

The kernel handles understanding, learning and acting. Each contributor adds their country's regulator, grid operator, permitting iter and market schemes. Italy is the reference module — fork it for yours.
